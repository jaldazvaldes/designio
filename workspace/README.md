# workspace

Aquí viven tus documentos de designio (`<carpeta>/<nombre>.designio.json`), las maquetas HTML que
crea la IA y `designio.config.json` con los proyectos que conectas.

Todo esto es local y **no se sube al repositorio** (ver `.gitignore`): puede mencionar proyectos
privados, rutas de tu equipo o decisiones internas. Si quieres versionar tus diseños, usa un
repositorio aparte (privado) para esta carpeta o apunta `DESIGNIO_WORKSPACE` a otra ruta.

Para empezar, copia `designio.config.example.json` como `designio.config.json`.
